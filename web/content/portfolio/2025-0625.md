# ポートフォリオサイトのバックエンド開発 - Contact APIの実装

## 概要

ポートフォリオサイトのお問い合わせ機能のバックエンドを実装しました。Express.js + TypeScript + Prisma + PostgreSQLを使用して、セキュアで実用的なContact APIを構築しました。

## 技術スタック

- **フレームワーク**: Express.js
- **言語**: TypeScript
- **ORM**: Prisma
- **データベース**: PostgreSQL
- **バリデーション**: Zod
- **セキュリティ**: reCAPTCHA, レート制限
- **メール送信**: Nodemailer
- **開発環境**: Docker Compose

## 実装した機能

### 1. Contact API（POST /api/contact）

```typescript
// バリデーションスキーマ
const contactSchema = z.object({
  name: z.string().min(1, "名前は必須です。").max(50, "名前は50文字以内で入力してください。"),
  email: z.string().email("メールアドレスの形式が正しくありません。"),
  subject: z.string().min(1, "件名は必須です。").max(100, "件名は100文字以内で入力してください。"),
  message: z.string().min(1, "メッセージは必須です。").max(1000, "メッセージは1000文字以内で入力してください。"),
  recaptchaToken: z.string().min(1, "reCAPTCHAの検証が必要です。"),
});
```

### 2. セキュリティ機能

- **レート制限**: 1分間に3回まで
- **reCAPTCHA検証**: Google reCAPTCHAによるスパム対策
- **バリデーション**: Zodによる型安全なバリデーション

### 3. データベース設計

```prisma
model Contact {
  id        Int      @id @default(autoincrement())
  name      String   @db.VarChar(50)
  email     String   @db.VarChar(255)
  subject   String   @db.VarChar(100)
  message   String   @db.VarChar(1000)
  createdAt DateTime @default(now())
}
```

## 遭遇した問題と解決方法

### 1. npm権限エラー

**問題**: npmのキャッシュディレクトリに権限の問題が発生

**エラーメッセージ**:
```
npm error EACCES: permission denied, mkdir '/Users/username/.npm/_cacache/content-v2/sha512/43/4e'
```

**解決方法**:
```bash
# npmキャッシュの削除
sudo rm -rf /Users/username/.npm/_cacache

# 権限の修正
sudo chown -R 502:20 "/Users/username/.npm"
```

### 2. データベース認証エラー

**問題**: PostgreSQLの接続情報が正しくない

**エラーメッセージ**:
```
Error: P1000: Authentication failed against database server
```

**解決方法**: Docker Composeの設定と`.env`ファイルの`DATABASE_URL`を一致させる

```env
# 修正前
DATABASE_URL="postgresql://postgres:password@localhost:5432/portfolio_db"

# 修正後
DATABASE_URL="postgresql://postgres:postgres@localhost:5432/portfolio"
```
